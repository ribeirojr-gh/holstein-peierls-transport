# IP1n — gauge-continuous field-release audit of isotropic post-hop lattice memory

## Motivation

IP1m is numerically closed but its preregistered carrier-centered d1 -> d2 retrograde-wake gate fails. The complete saved trajectory shows why: after the single isotropic natural hop, the B-centered trailing current is spatially phase-structured rather than a monotonic outward front. d=1 and d=4 remain strongly outward, d=2 remains inward, and d=3 changes sign. Reprojecting the same trajectory into the older event-source frame exactly reproduces the IP1k 634 fs correlation, proving that the frame difference is physical rather than numerical.

Because the electric field remains on throughout IP1m, a long-lived post-hop current pattern can contain both stored lattice excitation and continuing field support.

IP1n asks the causal question:

> Does the phase-structured trailing lattice-current pattern survive after external electrical work is switched off continuously in the vector-potential gauge?

## Gauge-continuous field release

The production field is represented by a Peierls phase generated by a linearly changing vector potential. An abrupt replacement by a zero-phase Hamiltonian would create an artificial gauge discontinuity.

Instead, after the first persistent hop is accepted, construct a held-phase continuation:

- the Peierls phases at the switch time are retained exactly;
- the phases remain constant thereafter;
- phase rates are exactly zero;
- therefore the post-switch electric field and external power are zero;
- the Hamiltonian is continuous at the switch.

The constant vector potential after release is gauge-equivalent to zero electric field while preserving the wavefunction/Hamiltonian representation continuously.

Propagate under the normal field until the first persistent nearest-neighbor x relocation is accepted. The expected screened event is 820 -> 819 with transition start near 2826 fs and acceptance near 2874 fs, but both times must be detected from the new run.

At the exact accepted sample time `ts`, clone the full coupled state into two deterministic branches:

1. **field-on branch**: continue with the original +10 mV/A field;
2. **released branch**: continue with the Peierls phase held at its value at `ts`, giving zero phase rate and zero external power.

Continue both branches for 2000 fs after `ts`.

## Common post-hop frame

The accepted event is A -> B. Define C as the next nearest neighbor in the same hop direction and use B -> C as the fixed post-hop residence frame.

- +s follows carrier motion;
- -s is trailing/retrograde;
- primary trailing boundaries: d=1,2,3,4.

The frame definition is identical in both branches.

## Pre-hop field background

During the common pre-branch driven trajectory, store the lattice-current field.

Use the B-centered interval

- transition start `t0 - 700 fs` to `t0 - 100 fs`

as the pre-hop field-only reference.

Subtract the mean longitudinal profile from both post-switch branches.

For the primary phase-structured memory observable, construct 100 fs background windows sampled every 20 fs inside this pre-hop reference interval.

## Trailing-pattern amplitude

For every sampled time define the four-component outward-current vector

`J_trail(t) = [J_back(d=1), J_back(d=2), J_back(d=3), J_back(d=4)]`.

Because IP1m established sign alternation across these boundaries, define the primary amplitude

`A_trail(t) = sqrt(mean_d J_trail(d,t)^2)`.

This quantity measures the strength of the phase-structured trailing lattice-current pattern without falsely requiring every boundary to carry outward current simultaneously.

For each 100 fs window record:

1. RMS of `A_trail(t)`;
2. maximum `A_trail(t)`;
3. signed mean current at each d=1..4;
4. positive and net transported energy at each boundary;
5. cosine similarity of the four-component mean-current vector with the corresponding field-on vector at the same relative time.

## Background separation

From the pre-hop reference, form empirical distributions of 100 fs window RMS and peak `A_trail`.

A post-switch 100 fs window is **pattern-separated** when both:

- RMS amplitude >= 95th percentile of pre-hop background;
- peak amplitude >= 95th percentile of pre-hop background.

These are robustness discriminators, not independent-sample p-values.

## Stored-memory gate for the released branch

The released branch supports autonomous stored lattice memory when:

1. at least three pattern-separated bins have centers more than 1000 fs after switch;
2. at least one pattern-separated bin has center >= `ts + 1500 fs`;
3. released-branch post-switch external work is zero to numerical precision;
4. released-branch matter energy is conserved within the established size-aware tolerance.

Report late passing fraction and latest passing center.

This gate deliberately measures the spatial current pattern rather than a single-boundary outward wake.

## Directional secondary diagnostics

Without using them as primary acceptance gates, report:

- d1..d4 positive/net energies in each branch;
- fraction of time each boundary carries positive outward current;
- late released-branch directionality based on summed positive outward energies over d=1..4;
- early d3 -> d4 normalized delay correlation, because IP1m found both boundaries outward during the early post-hop interval;
- whether any d1 -> d2 packet emerges after field release.

Normalized delay correlations must not be interpreted as transport unless the relevant upstream and downstream boundaries both carry physically outward positive flux over the packet interval.

## Field-on comparison

Apply the same amplitude/background analysis to the field-on continuation.

Report:

- field-on sustained pattern-memory gate;
- released/on ratio of late RMS amplitude;
- released/on ratio of integrated absolute trailing current;
- time-resolved cosine similarity between branch current vectors.

Interpretation:

- released PASS + field-on PASS: memory is stored in the matter state and may also be modified by ongoing drive;
- released FAIL + field-on PASS: the long-lived pattern requires continued field support;
- both FAIL: the IP1m pattern was transient under the stricter post-acceptance audit.

## Interpretation guards

- Field release is a controlled numerical intervention, not a material pulse protocol.
- A constant vector potential after release is physically zero electric field but is retained to preserve gauge continuity.
- Pattern persistence demonstrates stored coherent lattice/electronic-state memory; it does not by itself identify a unique phonon normal mode.
- Alternating boundary signs are not converted into a fictitious monotonic backward energy flux.
- No mobility, hopping rate, activation energy, threshold field or calibrated lifetime is extracted.

## Decision after IP1n

If the released branch passes the sustained pattern-memory gate, the next stage should perform a mode-resolved decomposition of the autonomous post-hop response (spatial wave number, frequency and polarization content) and quantify how much is Peierls/intermolecular versus intramolecular.

If only the field-on branch passes, the next stage should instead characterize the driven steady/coherent response and avoid calling it an autonomous wake.
