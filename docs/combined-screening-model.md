# Combined short-range and continuum screening model

## Purpose

Version `0.5.0a1` validated the frozen-distance continuum interaction

`V(r) = e^2 / (4 pi epsilon_0 epsilon_r r)`

and the special case in which a scalar `V1` replaces the continuum value on the
four cardinal nearest-neighbour bonds. The next controlled step is to separate
**effective short-range screened matrix elements** from the **continuum tail**
without assuming that a single dielectric expression remains quantitatively
valid at every molecular contact.

This document defines that model extension and its validation sequence. It does
not yet assign pentacene-specific short-range values.

## Physical motivation

Generalized-Hubbard descriptions of molecular crystals commonly distinguish
explicit low-energy Coulomb matrix elements from the screening generated by the
remaining molecular and crystal degrees of freedom. Real-space screening
calculations for organic molecular crystals also show that appreciable
longer-range interactions can coexist with strongly renormalized short-range
matrix elements. This motivates treating the first few intermolecular shells as
explicit effective parameters while retaining a dielectric continuum form only
outside the selected short-range region.

The present implementation therefore avoids introducing a single arbitrary
"Coulomb cutoff" that would silently set all interactions inside a distance to
the same value. Instead, every short-range replacement is explicit and
shell-resolved.

## Interaction definition

The onsite value remains

`V(0,0) = U`.

For every distinct-site pair, the baseline long-range interaction is

`V_cont(dx,dy) = 14.3996454784255 / (epsilon_r r(dx,dy))` eV,

with

`r(dx,dy) = sqrt[(a_x dx)^2 + (a_y dy)^2]`

using absolute minimum-image offsets on the finite periodic lattice.

Selected short-range shells may then replace that baseline value through

`short_range_shell_overrides = ((dx, dy, value_eV), ...)`.

Examples are

- `(1, 0, Vx)` for the two x-oriented nearest neighbours;
- `(0, 1, Vy)` for the two y-oriented nearest neighbours;
- `(1, 1, Vdiag)` for the four first diagonal neighbours;
- `(2, 0, V2x)` or `(0, 2, V2y)` for second axial shells when a sensitivity
  study requires them.

The scalar `nearest_neighbor_v` remains as a backward-compatible shorthand for
an isotropic cardinal replacement. To prevent ambiguous double definitions, a
nonzero `nearest_neighbor_v` cannot be combined with explicit `(1,0)` or `(0,1)`
overrides. It may be combined with additional shells such as `(1,1)`.

The onsite shell `(0,0)` cannot be overridden: `U` remains independent.

## Why shell offsets rather than only physical distance

The stationary Holstein-Peierls lattice can be anisotropic. Two shells with
similar physical distances may correspond to different packing directions,
transfer integrals, orbital overlaps, and microscopic screening environments.
Using `(dx,dy)` therefore preserves the lattice topology and permits controlled
anisotropic short-range parameters without changing the continuum geometry.

## Backward compatibility

With

`short_range_shell_overrides = ()`,

the interaction matrix is exactly the `v0.5.0a1` model.

With `long_range_coulomb = False`, explicit shell overrides are rejected in this
first implementation. This restriction is deliberate: the new option is a
short-range **replacement of the validated continuum model**, not a silent
redefinition of the already validated `U + V1` extended-Hubbard sector.

## Validation sequence

The implementation should be promoted in the following order.

1. **Matrix-element tests**
   - verify x, y, diagonal, and second-shell replacements analytically;
   - verify periodic symmetry of every selected shell;
   - verify that unselected pairs retain the continuum value;
   - verify that onsite `U` remains unchanged.

2. **Compatibility tests**
   - empty override tuple reproduces `v0.5.0a1` exactly;
   - scalar `V1` plus a diagonal override reproduces the old cardinal values
     while modifying only the diagonal shell;
   - conflicting cardinal definitions are rejected.

3. **Stationary-gradient regression**
   - because distances remain frozen, shell replacements add no new explicit
     structural-force term;
   - finite-difference checks must nevertheless confirm that the relaxed
     electronic state continues to produce the correct total structural
     gradient.

4. **Generic isotropic sensitivity study**
   - retain the validated `Jx = Jy = 0.0575 eV`,
     `alpha_x = alpha_y = 0.10 eV/angstrom`, and `a = 7 angstrom` control;
   - compare pure continuum, cardinal-only replacement, cardinal+diagonal
     replacement, and a deliberately extended second-shell replacement;
   - locate dissociation relative to the authoritative `2 E_polaron` reference;
   - determine whether the phase topology is robust to the chosen replacement
     range.

5. **Anisotropic sensitivity study**
   - permit independent `Vx` and `Vy` through explicit `(1,0)` and `(0,1)`
     replacements;
   - distinguish genuine screening anisotropy from hopping anisotropy.

6. **Material-specific parameterization only after sensitivity is understood**
   - obtain or compute physically justified short-range screened matrix elements
     and dielectric response for the target molecular crystal;
   - map those values onto the explicit shells rather than fitting a single
     effective dielectric constant to all distances.

## Current approximation retained

The continuum and shell-replacement distances remain frozen to equilibrium
lattice spacings. Peierls coordinates modify hopping integrals but do not modify
Coulomb distances directly. Direct electrostatic Peierls forces therefore remain
a later model extension and should not be mixed into the shell-range sensitivity
study.

## Literature context

The modeling choice is consistent with the generalized-Hubbard viewpoint that
screened Coulomb parameters in molecular crystals are effective low-energy
matrix elements and that longer-range terms can remain important:

- L. Cano-Cortes, A. Dolfen, J. Merino, and E. Koch, *Physica B* **405**, S185-S187 (2010), DOI: `10.1016/j.physb.2009.12.079`.
- L. Cano-Cortes et al., *Eur. Phys. J. B* **56**, 173-176 (2007), "Coulomb parameters and photoemission for the molecular metal TTF-TCNQ".
- S. D. Ha, Y. Qi, and A. Kahn, *Chemical Physics Letters* **495**, 212-217 (2010), DOI: `10.1016/j.cplett.2010.06.085`.

These references motivate the separation of short- and longer-range screening;
they are not used here to assign numerical pentacene parameters.
